Preposition Adverbs are stuff like „worüber“, „womit“, „daran“. They are used to refer to parts of sentences in conversation. In English, the translation would be "about it", "with it", etc. Remember to only use them to refer to objects not people.

### Formation

If the preposition starts with a vowel (a, e, i, o, u), you must insert an "-r-" between the prefix and the preposition. For example, da + auf is darauf. 

| Preposition  | Da-compound          | Wo-compound        |
| :----------- | :------------------- | :----------------- |
| mit (with)   | damit (with it/that) | womit (with what?) |
| für (for)    | dafür (for it/that)  | wofür (for what?)  |
| auf (on/for) | darauf               | worauf             |
| über (about) | darüber              | worüber            |

### Usage

- Womit schreibst du? Ich schreibe mit einem Kuli.
- Ich habe einen Kuli. Ich schreibe damit.

- Worauf wartest du? Ich warte auf den Bus.
- Ich warte auf den Bus. Ich warte schon lange darauf.

- Woran denkst du? Ich denke an meinen Urlaub.
- Mein Urlaub beginnt morgen. Ich denke daran.
