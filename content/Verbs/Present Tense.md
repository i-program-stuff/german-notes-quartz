## Verb Endings

| Pronoun                 | Ending |
| ----------------------- | ------ |
| ich (I)                 | -e     |
| du (you)                | -st    |
| er/sie/es (he/she/it)   | -t     |
| ihr (you, pl. informal) | -t     |
| wir (we)                | -en    |
| Sie (you, formal)       | -en    |
| Sie (you, pl. formal)   | -en    |
| sie (they)              | -en    |

### Irregulars

##### if the stem ends in -t or -d and the suffix is -st or -t then:

Add an "e" before the suffix.

| Infinitive      | Stem   | Finite verb        |
| --------------- | ------ | ------------------ |
| arbeiten        | arbeit | arbeitet/arbeitest |
| kosten          | kost   | kostet/kostest     |
| reden (to talk) | red    | redet/redest       |

##### if the stem ends in -n or -m and the suffix is -st or -t then:

Just like before, add an "e" before the suffix.

| Infinitive         | Stem | Finite verb    |
| ------------------ | ---- | -------------- |
| atmen (to breathe) | atm  | atmet/atmest   |
| regnen (to rain)   | regn | regnet/regnest |

Exception: does not apply if it's mm or nn.
`Example: kommen -> du kommst / er kommt`

##### if the stem ends in -s, -ss, -ß, -x, -z, -tz and the suffix is -st:

Don't add an extra "s".

| Infinitive         | Stem | Finite verb |
| ------------------ | ---- | ----------- |
| reisen (to travel) | reis | reist       |
| heißen             | heiß | heißt       |

##### Vowel changes for **du** and **er/sie/es** forms:

This only applies to certain verbs called strong verbs.

The vowel changes are:
```
a -> ä
e -> i
e -> ie
```
for **du** and **er/sie/es** forms.

"ihr" is not affected.

| Infinitive          | Finite verb |
| ------------------- | ----------- |
| schlafen (to sleep) | er schläft  |
| essen               | sie isst    |
| sprechen            | du sprichst |
| lesen               | du liest    |
| sehen (to see)      | er sieht    |
##### Common Verbs that change from a to ä:

| Infinitive            | Finite verb            |
| --------------------- | ---------------------- |
| fahren (to drive)     | du fährst / er fährt   |
| halten (to hold/stop) | du hältst / er hält    |
| tragen (to carry)     | du trägst / er trägt   |
| waschen (to wash)     | du wäschst / er wäscht |
| fallen (to fall)      | du fällst / er fällt   |

##### Common Verbs that change from e to i:

| Infinitive        | Finite verb            |
| ----------------- | ---------------------- |
| geben (to give)   | du gibst / er gibt     |
| helfen (to help)  | du hilfst / er hilft   |
| treffen (to meet) | du triffst / er trifft |
| werfen (to throw) | du wirfst / er wirft   |

nehmen (to take) has extra spelling changes for du and er/sie/es: `du nimmst / er nimmt`

##### Common Verbs that change from e to ie:

| Infinitive | Finite verb          |
| ---------- | -------------------- |
| lesen      | du liest / er liest  |
| sehen      | du siehst / er sieht |
##### Special Irregulars: haben and sein:

| Pronoun                     | haben | sein |
| --------------------------- | ----- | ---- |
| ich (I)                     | habe  | bin  |
| du (you, informal)          | hast  | bist |
| er/sie/es (he/she/it)       | hat   | ist  |
| ihr (you, plural, informal) | habt  | seid |
| wir (we)                    | haben | sind |
| Sie (you, formal)           | haben | sind |
| Sie (you, plural, formal)   | haben | sind |
| sie (they)                  | haben | sind |
