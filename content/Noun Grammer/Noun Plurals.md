#### Clues for Masculine Nouns:

###### Adding **-e**:

Vast majority of masculine nouns just take an "-e" in the end.

| Singular  | Plural     |
| --------- | ---------- |
| der Beruf | die Berufe |
| der Film  | die Filme  |
| der Tisch | die Tische |
###### Adding umlaut + **-e**:

Often an umlaut is added if original stem has a, o, or u.

| Singular | Plural    |
| -------- | --------- |
| der Ball | die Bälle |
| der Zug  | die Züge  |
###### Nouns ending in -er, -el, -en:

They have no change but sometimes add an umlaut.

| Singular   | Plural     |
| ---------- | ---------- |
| der Kuchen | die Kuchen |
| der Apfel  | die Äpfel  |

Of course there are always irregulars such as der Mann → die Männer.

#### Clues for Feminine Nouns:

###### Adding **-e** or **-en**:

The huge majority of feminine nouns add -n or -en:

| Singular    | Plural        |
| ----------- | ------------- |
| die Frau    | die Frauen    |
| die Zeitung | die Zeitungen |
| die Sprache | die Sprachen  |

###### Adding umlaut + **-e**:

| Singular  | Plural     |
| --------- | ---------- |
| die Hand  | die Hände  |
| die Stadt | die Städte |

Once again exceptions exist: die Mutter → die Mütter; die Tochter → die Töchter.

#### Clues for Neuter Nouns:

###### Adding **-e**:

Vast majority of neuter nouns just take an "-e" in the end but no umlaut.

| Singular | Plural    |
| -------- | --------- |
| das Bein | die Beine |
| das Jahr | die Jahre |

###### Adding umlaut + **-er**:

| Singular | Plural     |
| -------- | ---------- |
| das Kind | die Kinder |
| das Buch | die Bücher |

###### Nouns ending in -chen or -lein:
These don't have changes in Plural and Non-Plural forms.

#### Foreign Words:

For these, an "-s" is added in the end.

| Singular | Plural    |
| -------- | --------- |
| der Chef | die Chefs |
| das Team | die Teams |
